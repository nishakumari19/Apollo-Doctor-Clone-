🏥 Apollo Doctor Destination Page Clone
This is a frontend-backend clone of the Apollo 24/7 General Physician/Internal Medicine destination page. The project showcases doctor listings, filters, and server-side SEO using modern web technologies like Next.js, Express, and MongoDB Atlas.

🔗 Live Demo
Frontend (Next.js on Vercel): https://apollo-doctor-clone.vercel.app

Backend (Express.js on Render)

🧩 Features
✅ Destination page UI mimicking Apollo 24/7.

✅ Functional filters (gender, fee, experience, consultation mode, language, specialization).

✅ REST APIs to add and fetch doctor data with pagination.

✅ MongoDB Atlas used as NoSQL database.

✅ Server-side SEO implemented for better discoverability.

🔧 Tech Stack
Frontend
Next.js (App Router)

Tailwind CSS for styling

Dynamic Filtering

SEO Meta Tags with Open Graph and Canonical URLs

Backend
Express.js

MongoDB Atlas (NoSQL database)

Mongoose for schema/model management

CORS, dotenv

📁 APIs
POST /api/add-doctor
Adds a new doctor to the database.

GET /api/list-doctor-with-filter?filters
Fetches doctors with filters and pagination.

⚙️ Deployment
Frontend: Deployed on Vercel

Backend: Deployed on Render

Database: Hosted on MongoDB Atlas
